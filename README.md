# MTProto Монитор

> 45 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-gentlekapath.github.io-67259d)](https://gentlekapath.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@mtprxtg-2aabee)](https://t.me/mtprxtg)

## Что внутри

- `45` проверенных прокси-серверов MTProxy: наши серверы @mtprxtg + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://gentlekapath.github.io/](https://gentlekapath.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
